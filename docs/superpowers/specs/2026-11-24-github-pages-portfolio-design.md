# GitHub Pages Portfolio & YouTube Lightbox Design

## Goal
Publish Alan Oliveira's portfolio on GitHub Pages, featuring 4 specific YouTube video highlights rendered in an elegant, responsive, distraction-free in-site cinema lightbox player.

## Architecture
- Single-page application using clean semantic HTML5, CSS3 with dark editorial aesthetic, and vanilla JavaScript.
- Direct integration of 4 YouTube video IDs in `index.html` without depending on external API quotas.
- Lightbox cinema modal: centered 16:9 responsive YouTube iframe with player controls, dim backdrop, and native fullscreen button.
- Clean deployment via GitHub Pages using `index.html` at repository root on branch `main`.

## Non-Goals
- No backend servers, databases, or frameworks (React, Vue, Node).
- No build steps or bundlers.
